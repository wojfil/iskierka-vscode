
## Iskierka Syntax Highlighting

Syntax highlighting for [the Iskierka programming language](https://github.com/wojfil/iskierka) in Visual Studio Code.

Use the command below to build this extension.
It should generate one file with the .vsix extension.
Inside Visual Studio Code, right click this file and press "Install Extension VSIX".

```
vsce package
```
